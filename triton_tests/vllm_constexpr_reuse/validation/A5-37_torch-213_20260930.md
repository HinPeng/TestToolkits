## 两项失败

- `test_operators.py::test_ngram_static_range[128]`
- `test_operators.py::test_ngram_static_range[2048]`

两者均在编译前端失败，没有进入设备 launch：

```text
TypeError: load() got an unexpected keyword argument 'care_padding'
triton.compiler.errors.CompilationError: at 32:23
```

首次触发点为 [kernels.py 中的 sampled token load](../kernels.py:677)，
对应上游 `spec_decode/ngram.py:40`。原函数另有两处同名参数。
已直接检查目标环境的 `tl.load` 签名，确认不包含 `care_padding`，
`triton.language.extra.cann.extension` 也没有替代的 `load`。
本次保留原码和失败记录，没有删除参数或将该用例标成通过。

仅验证指定的 19 个算子时，可在已配置的目标环境执行：

```bash
python run_suite.py --mode off --select 'not ngram and not renamed_pointwise and not copy_external_bound'
```

完整基线仍使用 `python run_suite.py --mode off`；它会在第一个 ngram 失败处退出。
本次独立的 `baseline_scan.py` 用于收集全部 61 个场景，包括失败后的场景。
